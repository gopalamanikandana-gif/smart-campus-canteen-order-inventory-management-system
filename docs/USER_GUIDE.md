# User Guide

## Student

### Register
1. Open the application.
2. Select Register.
3. Enter name, email and password.
4. Submit.

### Login
Enter your credentials and select Login.

### Place an order
1. Browse the menu.
2. Select Add to cart.
3. Adjust quantity.
4. Review total.
5. Select Place Order.
6. The confirmation appears and the order is listed under My Orders.

### Validation
The system prevents:
- unavailable items
- quantities above the configured maximum
- quantities above available stock
- orders outside canteen hours

## Admin

Use the admin credentials from the README for local demonstration.
Admin APIs are protected by role-based authorization.
